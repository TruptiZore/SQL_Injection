# SQL_Injection
SQL_Injection Information Security Project

A simple educational **Information Security** project that demonstrates how **SQL Injection** can affect a login system and how the vulnerability can be prevented using **Prepared Statements**.

The project provides two authentication modes: a **Vulnerable Login** that demonstrates SQL Injection and a **Secure Login** that uses parameterized queries to prevent the attack.
<br><br>
## Features
1. Vulnerable login demonstration
2. Secure login implementation
3. Demonstrates SQL Injection attack
4. Demonstrates authentication bypass
5. MySQL database integration
6. Displays secure logins, blocked attacks, and bypass attempts on dashboard
7. Live system activity and security logs

## Project Purpose

The main purpose of this project is to understand the **SQL Injection vulnerability**, observe how unsafe SQL queries can be exploited, and learn how **Prepared Statements / Parameterized Queries** can protect applications from SQL Injection attacks.
